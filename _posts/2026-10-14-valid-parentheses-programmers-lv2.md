## 문제 설명

`(`와 `)`로만 이루어진 문자열 `s`가 올바르게 짝지어졌으면 `true`, 아니면 `false`를 반환한다. `(`로 열렸으면 반드시 짝지어서 `)`로 닫혀야 한다.

```
"()()"   → true
"(())()" → true
")()("   → false
"(()("   → false
```

## 시행착오

**없었다.** 10개 테스트(예시 4개와 엣지 6개)가 한 번에 모두 통과했다. 힌트도 받지 않았다. 직전까지 LC1021(바깥 괄호 벗기기)에서 이틀 연속 막혀서 괄호 문제 자체가 부담이었는데, 이 문제는 **"짝이 맞는지만" 판단**하는 가장 기본형이라 부담 없이 풀렸다.

## 최종 코드

```java
boolean solution(String s) {
    Deque<Character> deque = new ArrayDeque<>();
    for (int i = 0; i < s.length(); i++) {
        if (s.charAt(i) == '(') {
            deque.push('(');
        } else if (s.charAt(i) == ')') {
            if (!deque.isEmpty() && deque.peek() == '(') {
                deque.pop();                 // 맨 위가 '('이면 짝을 맞춤
            } else {
                deque.push(')');             // 짝이 없으면 ')'를 쌓아 둠
            }
        }
    }

    return deque.size() > 0 ? false : true;
}
```

10개 테스트가 모두 통과했고, 랜덤 50,000건에서 정답 판정과 일치했다. 길이 100,000 입력도 3ms였다.

## 추적표: `"())("`

| i | 문자 | 스택(맨 위가 앞) | 처리 |
|---|---|---|---|
| 0 | `(` | [ ( ] | push |
| 1 | `)` | [ ] | 맨 위가 `(` → pop(짝 맞춤) |
| 2 | `)` | [ ) ] | 스택이 비어 있음 → `)` push |
| 3 | `(` | [ ( , ) ] | push |

끝나고 스택이 비어 있지 않으니 `false`다. **`(`와 `)`의 개수가 같아도** 중간에 짝 없는 `)`가 있으면 틀린다.

## 오늘 배운 내용

**괄호 문제는 "맨 위가 짝인가?"만 본다.** `)`가 들어오면 스택 맨 위가 `(`인지만 확인하고, 맞으면 `pop`(짝 맞춤), 아니면 짝이 없다는 뜻이다. 이 판단 하나가 LC1614(괄호 깊이), LC1021(바깥 괄호), 올바른 괄호 모두의 밑바탕이다.

## 오답노트

- **틀린 곳은 없었다.** 확인할 점: 마지막 반환 `return deque.size() > 0 ? false : true;`는 `return deque.isEmpty();`로 줄일 수 있다. 조건식이 `true/false`를 그대로 돌려주면 삼항 연산자는 필요 없다.
- **좋았던 점**: `!deque.isEmpty()`를 `peek()` 앞에 쓰는 습관이 이번에도 처음부터 들어 있었다. 오늘 기능개발·카드 뭉치에서 배운 순서를 그대로 적용했다.

## 꿀팁

이 문제는 스택에 쌓이는 값이 전부 `(`이면 **개수만** 의미가 있다. 그래서 스택 대신 정수 하나(`open`)를 올리고 내려도 풀린다. 그러나 괄호 종류가 여러 개(`()`, `[]`, `{}`)가 되면 **무엇이 열렸는지**를 기억해야 하므로 스택이 필요하다. 이 문제는 한 종류라서 카운터로도 되는 특수한 경우다.

## AI라면 어떻게 풀었을까

`)`가 짝 없이 들어왔을 때 스택에 쌓아 두었다가 마지막 크기로 판단하는 대신, **그 순간 바로 `false`를 반환**한다. `(`만 `push`하고, `)`가 오면 스택이 비어 있는지 확인해서 비었으면 즉시 종료, 아니면 `pop`한다. 끝까지 돌았을 때 스택이 비어 있으면 모든 `(`가 짝을 찾은 것이다.

```java
boolean solutionAlt(String s) {
    Deque<Character> stack = new ArrayDeque<>();
    for (char c : s.toCharArray()) {
        if (c == '(') {
            stack.push(c);
        } else {
            if (stack.isEmpty()) {
                return false;                 // 짝 없는 ')' → 바로 실패
            }
            stack.pop();                      // '('와 짝을 맞춤
        }
    }
    return stack.isEmpty();                   // 짝 못 찾은 '('가 남았으면 false
}
```

트레이드오프: `)`를 스택에 쌓지 않아 스택에는 `(`만 남고, 짝 없는 `)`를 만나는 즉시 끝내서 긴 문자열에서 불필요한 반복을 줄인다. 반환도 한 줄이다. 대신 "스택에 남은 것이 곧 짝을 못 찾은 것"이라는 해석을 알고 있어야 읽힌다. 랜덤 50,000건에서 본인 풀이와 출력이 일치했다.
