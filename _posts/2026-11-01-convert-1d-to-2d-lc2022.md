## 문제 설명

1차원 배열 `original`을 **m행 n열** 2차원 배열로 채운다. 앞에서부터 n개가 첫 줄, 그다음 n개가 둘째 줄이 된다. 개수가 맞지 않으면 **빈 2차원 배열**을 반환한다.

```
[1,2,3,4], m=2, n=2  → [[1,2],[3,4]]
[1,2],     m=1, n=1  → []
```

금요일에 푼 [Reshape the Matrix]({% post_url 2026-10-30-reshape-matrix-lc566 %})에서 "다시 채우기" 부분만 떼어 낸 문제다. 그때 채우기 루프는 코치가 준 코드였다. 그래서 그 부분을 혼자 다시 쓸 수 있는지 확인하려고 골랐다.

## 시행착오

**힌트 없이 약 11분 만에 한 번에 통과했다.**

금요일에는 `row`·`col`을 직접 올리면서 "줄 끝이면 다음 줄로" 분기를 쓰다가 한 칸씩 비는 버그로 오래 막혔다. 이번에는 방식을 바꿨다. **결과 배열 기준으로 이중 for**를 돌고, 원래 배열 위치만 `idx`로 하나씩 올렸다. 줄 바꿈은 바깥 for가 알아서 하니까 줄 끝 분기 자체가 없다.

## 최종 코드

```java
public int[][] construct2DArray(int[] original, int m, int n) {
    int[][] answer = {};
    if (original.length != (n * m)) {
        return answer;                         // 개수가 안 맞으면 빈 배열
    }

    answer = new int[m][n];
    int idx = 0;                               // original에서 읽을 위치
    for (int j = 0; j < m; j++) {              // 결과 배열 기준
        for (int k = 0; k < n; k++) {
            answer[j][k] = original[idx];
            idx++;
        }
    }
    return answer;
}
```

`m * n`은 최대 4만 × 4만 = 16억이라 `int` 범위(약 21억) 안에 들어간다.

## 추적표: `[1,2,3,4,5,6], m=2, n=3`

| j | k | idx | 넣는 칸 |
|---|---|---|---|
| 0 | 0 | 0 | answer[0][0] ← 1 |
| 0 | 1 | 1 | answer[0][1] ← 2 |
| 0 | 2 | 2 | answer[0][2] ← 3 |
| 1 | 0 | 3 | answer[1][0] ← 4 |
| 1 | 1 | 4 | answer[1][1] ← 5 |
| 1 | 2 | 5 | answer[1][2] ← 6 |

→ `[[1,2,3],[4,5,6]]`

## 오늘 배운 내용

**칸을 채우는 방식은 "결과 배열 기준 이중 for + 읽는 위치 idx"가 가장 단순하다.** 줄을 넘기는 일은 바깥 for가 맡는다. 그래서 금요일처럼 "줄 끝 확인" 분기를 직접 쓰다가 생기는 실수가 사라진다. [Transpose Matrix]({% post_url 2026-10-30-transpose-matrix-lc867 %})에서 배운 "어느 배열 기준으로 도는가"를 여기서도 썼다.

## 오답노트

- **틀린 곳 없음.** 금요일에 받은 코드를 그대로 외워 쓰지 않고, 더 단순한 구조로 바꿔서 혼자 풀었다.

## AI라면 어떻게 풀었을까

본인 풀이가 가장 읽기 쉽다. 다른 방법은 1차원 인덱스 `i` 하나로 돌면서 **행 = `i / n`, 열 = `i % n`**으로 바로 넣는 것이다.

```java
public int[][] construct2DArrayAlt(int[] original, int m, int n) {
    if (original.length != m * n) {
        return new int[0][];                       // 빈 2차원 배열
    }
    int[][] answer = new int[m][n];
    for (int i = 0; i < original.length; i++) {
        answer[i / n][i % n] = original[i];        // i번째 칸 → 행 = 몫, 열 = 나머지
    }
    return answer;
}
```

트레이드오프: 루프가 하나라 짧지만, `/`와 `%`의 뜻을 알아야 읽힌다. 다음 문제(Shift 2D Grid)에서 이 공식을 직접 써 본다. 랜덤 20,000건에서 두 풀이의 결과가 같았다.
