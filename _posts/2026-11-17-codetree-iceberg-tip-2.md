## 문제 설명

일렬로 놓인 빙산의 높이 `H(i)`가 주어진다. 해수면 `s`(0 이상의 정수)에서 `H(i) <= s`는 잠기고 `H(i) > s`만 드러난다. 번호가 이어지는 드러난 빙산은 한 덩어리다. `s`를 잘 정했을 때 덩어리의 최대 개수를 구한다.

```
9
3 5 2 3 2 1 4 2 3   → 4   (s = 2: 1~2번, 4번, 7번, 9번)
```

## 시행착오

`s`를 0부터 최댓값까지 하나씩 정하고, 그때 덩어리 수를 세어 최댓값을 고르는 틀은 처음부터 맞았다. 틀린 곳은 **덩어리를 세는 방법**이었다.

### 1. 잠긴 빙산을 셌다

```java
if (h[j] <= i) { count++; keep = false; } else { keep = true; }
```

`h[j] <= i`는 잠긴 빙산인데 거기서 `count++`를 했다. 문제가 세라는 건 드러난 덩어리다. 예제 첫 입력에서 정답 4가 아니라 9가 나왔다.

### 2. 덩어리는 "시작"만 센다

덩어리 안의 모든 빙산을 세면 안 되고, **새 덩어리의 첫 칸**만 센다. 첫 칸의 조건은 **지금 칸이 드러났고, 바로 앞 칸이 잠겼거나 맨 처음 칸**이다. `keep`을 "바로 앞 칸이 드러났는가"로 쓰면 된다.

### 3. `else`가 두 경우를 섞었다

```java
if (h[j] > i && !keep) { count++; keep = true; }
else { keep = false; }     // 잠겼을 때와, 드러났는데 앞 칸도 드러났을 때가 같이 실행됨
```

드러난 빙산이 연속이면 둘째 칸에서 `keep`이 꺼지고, 셋째 칸에서 또 센다. `1 1 1`, `s = 0`이면 정답 1인데 2가 나온다. `keep = false`는 **잠겼을 때만** 해야 한다.

### 4. `keep`은 `s`마다 다시 시작해야 한다

선언을 `s` 루프 바깥에 두면 이전 `s`의 마지막 상태가 다음 `s`로 넘어간다. `s` 루프 안에서 `false`로 초기화한다.

## 최종 코드

```java
int ans = 0;
boolean keep = false;
for (int i = 0; i <= maxHeight; i++) {
    int count = 0;
    keep = false;
    for (int j = 0; j < h.length; j++) {
        if (h[j] > i && !keep) {
            count++;
            keep = true;
        } else if (h[j] <= i && keep) {
            keep = false;
        }
    }
    ans = Math.max(ans, count);
}
```

## 추적표: `3 5 2 3 2 1 4 2 3`, s = 2

| j | h[j] | 드러남? | keep(전) | count | keep(후) |
|---|---|---|---|---|---|
| 0 | 3 | O | F | 1 | T |
| 1 | 5 | O | T | 1 | T |
| 2 | 2 | X | T | 1 | F |
| 3 | 3 | O | F | 2 | T |
| 4 | 2 | X | T | 2 | F |
| 5 | 1 | X | F | 2 | F |
| 6 | 4 | O | F | 3 | T |
| 7 | 2 | X | T | 3 | F |
| 8 | 3 | O | F | 4 | T |

덩어리 4개.

## 오늘 배운 내용

- "연속한 것의 개수"를 셀 때는 안의 원소를 세지 않고 **시작점만** 센다. 시작점 = 지금 조건을 만족하고 직전 칸은 만족하지 않는 곳.
- "직전 칸의 상태"를 `boolean`으로 들고 가면, 그 변수는 **조건에 맞는 칸에서 켜고 맞지 않는 칸에서만 끈다.** 한 `else`에 두 경우를 섞으면 틀린다.
- 상태 변수는 반복 한 번(`s` 하나)이 시작될 때마다 초기화한다.

## 오답노트

- `else` 하나가 "잠김"과 "드러남 + 앞 칸도 드러남"을 같이 받는지 확인한다. 연속 입력(`1 1 1`)을 한 번 따라가 보면 바로 보인다.
- 틀린 출력이 크게 어긋나면(9) 세는 대상이 문제와 반대인지부터 본다.

## AI라면 어떻게 풀었을까

`keep` 변수 없이 **직전 칸을 직접 본다.**

```java
for (int s = 0; s <= maxHeight; s++) {
    int count = 0;
    for (int j = 0; j < n; j++) {
        boolean exposed = h[j] > s;
        boolean prevExposed = j > 0 && h[j - 1] > s;
        if (exposed && !prevExposed) count++;
    }
    ans = Math.max(ans, count);
}
```

상태 변수가 없어서 "언제 끄는가" 실수가 없다. `s`는 실제 높이 값들만 시도해도 같은 답이 나온다.
