공모전 MVP 범위를 바꿨다. 실제 전화번호와 전화 서버(Asterisk) 없이, **민원인 앱과 상담원 앱이 폰 마이크로 통화**하고 모든 음성이 음성 게이트웨이를 거치게 한다. 앱 개발과 게이트웨이 개발이 동시에 진행되기 때문에, 코드보다 먼저 **둘 사이의 연동 규격**을 확정했다 ([PR #12](https://github.com/GovTech-korea/GovTech-Korea_VoiceGateway/pull/12)).

## 구조

```
민원인 앱 ──음성──▶ VOICE_GATEWAY ──(0.5~1초 지연)──▶ 상담원 앱
                        │
                        └─ 즉시 STT ─▶ 위험 감지 시 아직 안 나간 구간을 무음 처리

상담원 앱 ──음성──▶ VOICE_GATEWAY ──(지연 없음)──▶ 민원인 앱
```

핵심은 **민원인 음성을 상담원에게 0.5~1초 늦게 전달**하는 것이다. 그 사이에 민원인 음성을 STT로 돌려 폭언을 찾고, 찾으면 아직 상담원에게 나가지 않은 구간을 무음으로 바꾼다. 폭언이 상담원 귀에 닿기 전에 막는 구조다.

처음에는 "상담원의 말을 늦춘다"로 이야기가 나왔는데, 따져 보면 상담원 말을 늦춰서는 민원인 음성을 분석할 시간이 늘지 않는다. 늦출 쪽은 민원인 → 상담원 방향이다.

## 왜 WebSocket 하나인가

전화망을 거치지 않으니 앱과 게이트웨이는 **WebSocket 연결 하나**만 있으면 된다.

| 방향 | 메시지 | 내용 |
|---|---|---|
| 앱 → 게이트웨이 | 텍스트(JSON) `join` | 통화 ID, 역할(CITIZEN/AGENT), 음성 형식 |
| 앱 → 게이트웨이 | 바이너리 | 20ms마다 내 음성 |
| 게이트웨이 → 앱 | 바이너리 | 상대 음성 |
| 게이트웨이 → 앱 | 텍스트(JSON) | joined, peer-joined, peer-left, error |

같은 `callId`로 접속한 민원인 1명과 상담원 1명이 연결된다. 두 앱은 같은 방식으로 접속하고 `role` 값만 다르다.

## 음성 형식: PCM16, 16kHz, mono, 20ms

| 항목 | 값 |
|---|---|
| 인코딩 | PCM 16비트 signed, little-endian |
| 샘플링 | 16,000Hz |
| 채널 | mono |
| 프레임 | 20ms = 320샘플 = **640바이트** |

## 새로 배운 것 1: "mono"와 "PCM"은 선택지가 아니다

STT 형식을 정할 때 "16k mono, 8k mono, 16k PCM, 8k PCM 네 가지"로 이야기가 나왔다. 그런데 이 둘은 서로 다른 축이다.

- **PCM**: 소리를 숫자로 저장하는 방식(인코딩). 보통 16비트 정수
- **mono / stereo**: 채널 수
- **16k / 8k**: 1초에 몇 번 측정하는지(샘플링)

그래서 실제로 고를 것은 "16kHz냐 8kHz냐"와 "헤더 없는 원시 바이트냐 WAV냐" 정도다. 이번에는 WAV를 쓰지 않기로 해서, 게이트웨이가 STT에 넘기는 형식은 **PCM16 16kHz**와 **PCM16 8kHz** 두 가지로 정했다. 앱은 항상 16kHz로 보낸다. 16kHz를 8kHz로 낮추는 건 게이트웨이가 할 수 있지만, 8kHz로 받아서 16kHz로 올리면 잃어버린 음질이 돌아오지 않기 때문이다.

## 새로 배운 것 2: 640바이트가 나오는 계산

```
16,000 샘플/초 × 0.02초 = 320 샘플
320 샘플 × 2바이트(16비트) × 1채널 = 640 바이트
```

실시간성을 위해 조각을 작게 보내지만, 조각마다 STT를 따로 부르는 게 아니다. **STT 스트리밍 연결 하나에 20ms 조각을 계속 흘려 넣고**, STT는 중간 결과를 계속 돌려준다. 너무 잘게 자르면 네트워크 부담만 늘어서, 20ms는 실시간성과 부담 사이의 흔한 선택이다.

## 새로 배운 것 3: 에코가 STT를 속인다

민원인 폰 스피커에서 나온 상담원 목소리가 민원인 마이크로 다시 들어가면, 게이트웨이는 그것을 **민원인의 말**로 받아 STT에 넣는다. 그래서 규격에 Android 녹음 입력 소스를 `VOICE_COMMUNICATION`으로 쓰라고 못 박았다. 통화용 입력이라 에코 제거와 잡음 억제가 켜진다.

```kotlin
val recorder = AudioRecord(
    MediaRecorder.AudioSource.VOICE_COMMUNICATION,
    16_000,
    AudioFormat.CHANNEL_IN_MONO,
    AudioFormat.ENCODING_PCM_16BIT,
    bufferSize
)
```
