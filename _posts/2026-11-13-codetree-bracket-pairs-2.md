## 문제 설명

`(`와 `)`로 된 문자열에서, `((`가 시작하는 위치 `i`와 `))`가 시작하는 위치 `j`를 짝지은 `(i, j)`의 개수를 센다. 조건은 `i + 2 <= j`(두 구간이 겹치지 않음).

```
)((()())())   → 4   ((2,7), (2,10), (3,7), (3,10))
```

## 시행착오

"((" 위치 후보와 "))" 위치 후보를 하나씩 짝지어 보는 이중 반복문이다.

- 바깥 `i`: `charAt(i)`와 `charAt(i+1)`이 모두 `(`인 위치.
- 안쪽 `j`: `i + 2`부터. 이렇게 하면 `i + 2 <= j` 조건이 시작값으로 처리된다.
- 둘 다 `charAt(+1)`을 읽으므로 반복문 끝을 `length() - 1`로 잡아 범위를 넘지 않게 했다.

## 최종 코드

```java
int counter = 0;
for (int i = 0; i < str.length() - 1; i++) {
    if (str.charAt(i) == '(' && str.charAt(i + 1) == '(' && (i + 1) != str.length() - 1) {
        for (int j = i + 2; j < str.length() - 1; j++) {
            if (str.charAt(j) == ')' && str.charAt(j + 1) == ')') {
                counter++;
            }
        }
    }
}
```

## 추적표: 예제 `)((()())())` (0-indexed)

`((`는 i = 1, 2, `))`는 j = 6, 9.

| i | j 후보 | 센 개수 |
|---|---|---|
| 1 | 6, 9 | 2 |
| 2 | 6, 9 | 2 |

합계 4.

## 오늘 배운 내용

- "겹치면 안 된다"는 조건은 **두 번째 반복문의 시작값**으로 처리한다.
- `charAt(i+1)`을 쓰면 반복 범위는 `length() - 1`까지.

## 오답노트

- `(i + 1) != str.length() - 1` 조건은 바로 아래 `j` 반복문이 어차피 돌지 않아서 없어도 결과가 같다. 쓸모없는 조건은 지운다.

## AI라면 어떻게 풀었을까

왼쪽에서 오른쪽으로 한 번만 훑으면서 "지금까지 나온 `((`의 개수"를 들고 가다가, `))`를 만나면 그 개수를 더한다.

```java
int open = 0, ans = 0;
for (int k = 0; k + 1 < s.length(); k++) {
    if (k >= 2 && s.charAt(k - 2) == '(' && s.charAt(k - 1) == '(') open++;
    if (s.charAt(k) == ')' && s.charAt(k + 1) == ')') ans += open;
}
```

`k - 2`에서 시작한 `((`는 `k`의 `))`와 겹치지 않으므로 그때 편입한다. O(N).
