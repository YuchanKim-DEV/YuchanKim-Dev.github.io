- 문제 링크: 코드트리 야바위 (Chapter 8 > Lesson 1. 상황을 일일이 가정해보고 진행하는 완전탐색)
- 파일 경로: `src/main/java/coding_test/완전탐색/CT_야바위.java`
- 난이도: Easy, 20XP (정답률 70%)
- 제한: 1 ≤ N ≤ 100, 1 ≤ a, b, c ≤ 3, a ≠ b (1초, 64MiB)

## 문제 설명

종이컵 3개(자리 1, 2, 3) 중 하나 아래에 조약돌이 있다. N번의 연산에서 각각 `a`번과 `b`번 **자리**의 컵을 맞바꾼 뒤 `c`번 자리 컵을 열어 조약돌이 있으면 1점이다. 처음 조약돌을 어느 자리에 넣을지 잘 골랐을 때의 최대 점수를 구한다.

```
3
1 2 1
3 2 1
1 3 1   → 2   (2번 자리에서 시작하면 2점)
```

## 시행착오

처음에는 문제가 이해되지 않았다. 입력의 숫자 세 개가 **컵의 이름이 아니라 자리 번호**이고, 한 줄이 연산 하나라는 점에서 막혔다. 예제를 시작 자리 2번으로 손으로 따라가 보고 나서 구조가 보였다.

- 시작 자리는 1, 2, 3번 **세 가지뿐**이다. 각각을 가정해서 연산 N개를 끝까지 따라가면 된다.
- 한 시작 자리의 점수는 `count`로 센다. 시작 자리마다 **0에서 새로** 시작한다.
- 마지막에 세 점수 중 최댓값을 고른다.

## 최종 코드

```java
int max = 0;
for (int i = 1; i <= 3; i++) {
    int count = 0;
    boolean[] pos = new boolean[3];     // 각 자리에 조약돌이 있는가
    if (i == 1) pos[0] = true;
    else if (i == 2) pos[1] = true;
    else pos[2] = true;

    for (int j = 0; j < ops.length; j++) {
        boolean temp = pos[ops[j][0] - 1];
        pos[ops[j][0] - 1] = pos[ops[j][1] - 1];
        pos[ops[j][1] - 1] = temp;       // a번과 b번 자리를 맞바꿈

        if (pos[ops[j][2] - 1]) {         // c번 자리를 열어 봄
            count++;
        }
    }
    max = Math.max(max, count);
}
```

## 추적표: 시작 자리 2번, 예제

| 연산 | 바꾼 뒤 조약돌 자리 | c번 열기 | 누적 점수 |
|---|---|---|---|
| 1 2 1 | 1 | 1번 → 있음 | 1 |
| 3 2 1 | 1 | 1번 → 있음 | 2 |
| 1 3 1 | 3 | 1번 → 없음 | 2 |

시작 1번은 1점, 3번은 0점이라 최댓값 2.

## 오늘 배운 내용

- 시작 상황이 몇 가지 안 되면 **전부 가정해서 끝까지 시뮬레이션**하고 최댓값을 고른다.
- "교환"은 임시 변수(`temp`) 하나로 두 값을 맞바꾼다. 여기서는 두 자리의 "조약돌 있음" 값을 바꿨다.
- 입력의 숫자가 이름인지 위치인지 먼저 구분한다. 이 문제는 전부 위치다.

## 오답노트

- 입력을 받는 `int[][] ops = new int[n][n];`은 열 개수가 N이다. `a, b, c` 3개를 저장해야 하므로 N이 1이나 2이면 `ops[i][2]`에서 범위 오류가 난다. 열은 3개여야 하므로 `new int[n][3]`이 맞다. 코드트리 테스트(N ≥ 3)에서는 통과했지만 작은 N이 있으면 틀릴 수 있다.
- 배열을 만들 때 크기를 "행 수"와 "열 수"로 따로 생각한다.

## AI라면 어떻게 풀었을까

조약돌은 하나뿐이므로 "각 자리에 있는가" 배열 대신 **조약돌이 있는 자리 하나(`pos`)만** 들고 간다.

```java
for (int start = 1; start <= 3; start++) {
    int pos = start, count = 0;
    for (int[] op : ops) {
        if (pos == op[0]) pos = op[1];
        else if (pos == op[1]) pos = op[0];
        if (pos == op[2]) count++;
    }
    max = Math.max(max, count);
}
```

`boolean[3]`을 맞바꾸는 내 방식은 "a번과 b번을 바꾼다"는 문장과 그대로 대응되는 장점이 있다.
