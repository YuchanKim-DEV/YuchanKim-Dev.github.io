- 문제 링크: 코드트리 수를 여러번 사용하여 특정 수 만들기 (Chapter 8 > Lesson 1)
- 파일 경로: `src/main/java/coding_test/완전탐색/CT_수를여러번사용하여특정수만들기.java`
- 난이도: Easy, 20XP (정답률 70%)
- 제한: 1 ≤ A < B < C ≤ 1000

## 문제 설명

서로 다른 정수 A, B, C가 주어진다. A와 B를 **0번 이상** 더해서 만들 수 있는 **C 이하**인 수 중 가장 큰 값을 구한다.

```
17 25 77   → 76   (17 × 3 + 25 × 1)
3 4 5      → 4    (3 × 0 + 4 × 1)
```

## 시행착오

이번에는 틀린 곳이 없었다. 구조는 단순하다. **A를 몇 번 쓸지(`i`)와 B를 몇 번 쓸지(`j`)를 각각 정하고**, 그 합이 C 이하이면 최댓값을 갱신한다.

- `i`의 범위는 `0 ~ C / A`, `j`의 범위는 `0 ~ C / B`. 이보다 많이 쓰면 합이 C를 넘으니 처음부터 제외한다.
- 합 `A*i + B*j`가 `C`를 넘지 않을 때만 최댓값 후보로 삼는다.
- `i = 0`, `j = 0`부터 시작해서 "한 번도 안 더하는 경우"(합 0)도 후보에 들어간다.

## 최종 코드

```java
int N = C / A;
int M = C / B;
int max = Integer.MIN_VALUE;
for (int i = 0; i <= N; i++) {
    for (int j = 0; j <= M; j++) {
        int num = (A * i) + (B * j);
        if (num <= C) {
            max = Math.max(max, num);
        }
    }
}
```

## 추적표: `17 25 77`

`N = 77/17 = 4`, `M = 77/25 = 3`.

| i | j | A·i + B·j | C 이하? | max |
|---|---|---|---|---|
| 3 | 1 | 51 + 25 = 76 | ✅ | 76 |
| 4 | 0 | 68 | ✅ | 76 (유지) |
| 2 | 1 | 34 + 25 = 59 | ✅ | 76 |
| 4 | 1 | 68 + 25 = 93 | ❌ | 76 |

모든 조합 중 최댓값은 76.

## 오늘 배운 내용

- "수를 여러 번 더해서 만든다"는 **각 수를 몇 번 쓸지를 정하는 이중 반복문**이다.
- 반복 횟수의 상한은 `C / 수`. 상한을 두면 불필요하게 큰 값을 계산하지 않는다.
- `0번` 사용하는 경우도 후보다. 반복문을 0부터 시작한다.

## 오답노트

- 이번에는 틀린 곳이 없었다.

## AI라면 어떻게 풀었을까

바깥 `i`만 정하고, 남은 값에서 B를 **넣을 수 있는 만큼만** 넣는다.

```java
int best = 0;
for (int i = 0; A * i <= C; i++) {
    int rest = C - A * i;
    best = Math.max(best, A * i + (rest / B) * B);
}
```

이중 반복문이 O(C/A × C/B)이고 이 방식은 O(C/A)다. C ≤ 1000이라 둘 다 충분하다.
