시작 화면 제목을 MOMIN 한 단어로 줄이고 나니 새 문제가 보였다. 제목은 왼쪽 끝, 해태는 오른쪽 끝에 붙어서 가운데가 텅 비었다. 통합 콘솔은 맨 아래 작은 글자 링크 하나뿐이라 팀원들이 찾지 못했다 ([PR #46](https://github.com/GovTech-korea/GovTech-Korea_VoiceGateway/pull/46)).

## 제목과 해태를 가운데로

원인은 `grid-template-columns: 1.15fr 0.85fr`였다. 긴 문장이 있을 때는 왼쪽 칸이 채워졌지만, 다섯 글자만 남으니 칸만 넓고 내용은 없었다. 칸 너비를 내용에 맞추고(`auto auto`) 묶음 전체를 가운데로 보냈다.

```css
.hero { grid-template-columns: auto auto; justify-content: center; gap: clamp(28px, 7vw, 88px); }
.hero h1 { font-size: clamp(64px, 11vw, 120px); }
```

한 단어 제목은 크게 써야 무게가 맞아서 글자도 키웠다.

## 통합 콘솔 입구 두 곳

- 헤더 오른쪽에 "통합 콘솔" 버튼
- 상담원·민원인 카드 아래에 점선 테두리 카드 (개발·시연용임을 표시)

## 콘솔 다시 그리기

콘솔만 예전 회색 관리자 화면이라 브랜드(남색·빨강)를 입혔다. 배치는 위에서부터 상담원|민원인 → 타임라인 → 게이트웨이|STT 서버 → STT로 보낸 음성이다.

- **STT 서버**: "연결 주소: ws://…" 한 줄 대신 서버·경로·언어·전체 주소로 나눠 보여 준다. 주소 바꾸기도 같은 섹션에 있다.
- **녹음**: 게이트웨이 표 사이에 끼어 있던 재생기를 별도 섹션 카드로 뺐다.

## 리뷰에서 잡은 것

- **적용 결과가 1초 만에 사라짐**: 주소를 잘못 넣어 400이 나도, 1초마다 도는 상태 갱신이 안내문을 바로 덮어썼다. 그래서 결과를 8초 동안 남긴다(`sttNoteUntil`).
- **역할 색이 서로 달랐음**: 패널에서는 상담원이 남색인데 타임라인에서는 상담원 줄이 빨강이었다. 타임라인 기준으로 통일했다.
