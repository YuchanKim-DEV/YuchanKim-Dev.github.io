- 문제 링크: 코드트리 가장 작은 x 찾기 (Chapter 8 > Lesson 1)
- 파일 경로: `src/main/java/coding_test/완전탐색/CT_가장작은x찾기.java`
- 난이도: Easy, 20XP (정답률 68%)
- 제한: 1 ≤ N ≤ 10, 1 ≤ a_i ≤ b_i ≤ 10,000

## 문제 설명

양의 정수 `x`에서 시작해 2를 곱하는 것을 N번 반복한다. `i`번째로 2를 곱한 직후의 값 `2^i × x`는 `a_i` 이상 `b_i` 이하여야 한다. N개의 조건을 모두 만족하는 **가장 작은 양의 정수 x**를 구한다.

```
4
1 10 / 10 16 / 20 25 / 40 50   → 3   (3 → 6 → 12 → 24 → 48)
```

## 시행착오

이번에는 틀린 곳이 없었다. 구조는 단순하다.

- `x`의 후보를 `1`부터 `10000`까지 **전부** 시도한다. 첫 곱셈 직후 값 `2x`가 `b_1`(최대 10000)을 넘으면 안 되므로 `x`는 5000 이하지만, 10000까지 돌려도 충분히 빠르다.
- 각 `x`마다 `num = x * 2`로 시작해서 조건 `j`번을 차례로 확인한다. 범위 안이면 `num *= 2`로 다음 단계로, 벗어나면 `checker = false`로 하고 `break`한다.
- 모든 조건을 통과한 `x`만 `Math.min`으로 답을 갱신한다.
- `checker`는 **`x`마다** `true`로 초기화한다. 이전 `x`의 결과가 이어지지 않는다.

## 최종 코드

```java
int ans = Integer.MAX_VALUE;
for (int i = 1; i <= 10000; i++) {
    int num = i * 2;                    // 첫 곱셈 직후 값부터 검사
    boolean checker = true;
    for (int j = 0; j < n; j++) {
        if (num >= a[j] && num <= b[j]) {
            num *= 2;                   // 다음 단계 값
        } else {
            checker = false;
            break;
        }
    }
    if (checker) {
        ans = Math.min(ans, i);
    }
}
System.out.print(ans);
```

## 추적표: 예제 1에서 `x = 3`과 `x = 2`

| x | 단계 | num | 범위 | 통과? |
|---|---|---|---|---|
| 3 | 1 | 6 | [1, 10] | ✅ |
| 3 | 2 | 12 | [10, 16] | ✅ |
| 3 | 3 | 24 | [20, 25] | ✅ |
| 3 | 4 | 48 | [40, 50] | ✅ → 후보 |
| 2 | 1 | 4 | [1, 10] | ✅ |
| 2 | 2 | 8 | [10, 16] | ❌ → 중단 |

`x = 1`은 두 번째에서 4라 실패하고, `x = 3`이 처음 통과하는 값이라 답은 3.

## 오늘 배운 내용

- **"가장 작은 값"을 구하는 완전탐색은 후보를 작은 것부터 전부 시도하고 조건에 맞으면 갱신한다.** `Math.min`과 `Integer.MAX_VALUE`로 시작하는 틀이다.
- 조건이 하나라도 어긋나면 그 후보는 끝이니 **`break`로 바로 중단**한다. 상태를 나타내는 `boolean`(`checker`)은 후보마다 `true`로 초기화한다.
- 곱셈이 `x`부터가 아니라 **`2x`부터** 검사된다는 문제 설명을 놓치지 않아야 한다. `num = i * 2`가 그 부분이다.

## 오답노트

- 이번에는 틀린 곳이 없었다.

## AI라면 어떻게 풀었을까

작은 `x`부터 보기 때문에 **처음 통과한 `x`가 곧 최솟값**이다. 그래서 `ans`와 `Math.min` 없이 바로 끝낼 수 있다.

```java
for (int x = 1; ; x++) {
    int v = x;
    boolean ok = true;
    for (int i = 0; i < n && ok; i++) {
        v *= 2;
        ok = a[i] <= v && v <= b[i];
    }
    if (ok) return x;
}
```

`x`의 상한은 `b[0] / 2`(첫 곱셈 직후 값 `2x`가 `b[0]` 이하여야 하므로) 이하라서 최대 5000이다.
