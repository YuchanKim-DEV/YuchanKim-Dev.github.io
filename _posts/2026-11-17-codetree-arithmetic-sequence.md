## 문제 설명

정수 N개가 주어진다. 자연수 K를 하나 정하면 `i < j`인 인덱스 쌍 중 `aj - K == K - ai`인 쌍이 **(ai, K, aj)가 등차수열**이다. K를 잘 골라 이런 쌍의 개수를 최대로 만들 때 그 값을 구한다.

```
4
7 6 4 3   → 2   (K=5: (7,5,3), (6,5,4))
```

## 시행착오

구조는 처음부터 맞았다. **K 후보를 하나씩 정하고, 그 K에서 가능한 모든 쌍을 센다.** 틀린 곳은 두 군데였다. (제한 조건: 정수는 모두 다르다.)

### 1. K가 바뀌어도 count를 비우지 않고, 최댓값도 안 골랐다

```java
int count = 0;                     // K 루프 바깥 → 모든 K의 합이 됨
...
System.out.print(count);
```

문제는 "K 하나를 정했을 때의 개수 중 최대"이므로, K 루프 안에서 `count = 0`으로 시작하고 끝에서 `ans = Math.max(ans, count)`를 한다.

### 2. (i, j)와 (j, i)를 둘 다 셌다

`j`를 처음부터 돌려서 같은 쌍이 두 번 들어갔다. `j`를 `k + 1`부터 돌린다.

### 조건을 "거리가 같다"로 바꿔 쓴 것은 괜찮았다

`Math.abs(a[j] - K) == Math.abs(a[k] - K)`로 썼다. 문제 식은 `aj - K == K - ai`, 즉 `ai + aj == 2K`다. 두 조건은 값이 같은 수가 있으면 달라지지만(K=5에서 7과 7), **이 문제는 정수가 모두 다르다고 했으므로** 같은 조건이 된다. 처음에는 이 제한을 놓치고 틀린 줄로 오해했는데, 제한 조건을 확인하고 바로잡았다.

## 최종 코드 (코드트리 통과 버전)

```java
int ans = 0;
for (int i = 0; i <= max_k; i++) {
    int count = 0;

    for (int k = 0; k < arr.length - 1; k++) {
        int temp = Math.abs(arr[k] - i);
        for (int j = k + 1; j < arr.length; j++) {
            if (Math.abs(arr[j] - i) == temp) {
                count++;
            }
        }
    }
    ans = Math.max(ans, count);
}
```

## 추적표: K = 5, `[7,6,4,3]`

| k | arr[k] 거리 | j | arr[j] 거리 | 센다? |
|---|---|---|---|---|
| 0 (7) | 2 | 1 (6) | 1 | ❌ |
| 0 (7) | 2 | 2 (4) | 1 | ❌ |
| 0 (7) | 2 | 3 (3) | 2 | ✅ |
| 1 (6) | 1 | 2 (4) | 1 | ✅ |
| 1 (6) | 1 | 3 (3) | 2 | ❌ |
| 2 (4) | 1 | 3 (3) | 2 | ❌ |

K=5에서 2개.

## 오늘 배운 내용

- "최댓값을 구하라"인 완전탐색은 **후보 하나마다 0에서 새로 세고, 끝날 때 최댓값 변수와 비교**하는 틀이다.
- 쌍을 셀 때는 `j`를 `i` 뒤에서 시작해 중복을 막는다.
- 조건은 문제의 식을 그대로 옮긴다. `aj - K == K - ai`는 `ai + aj == 2K`와 같다.

## 오답노트

- 변수를 쌓는 위치(K 루프 안/밖)를 먼저 정한다. 오늘 첫 오답의 원인이었다.
- `j`는 `k + 1`부터. 쌍 문제의 기본이다.
- **제한 조건을 먼저 읽는다.** "모두 다르다"는 제한 하나가 조건 변형이 안전한지 판단하는 기준이 됐다.

## AI라면 어떻게 풀었을까

조건을 문제 식 그대로 쓴다. `ai + aj == 2K`.

```java
int ans = 0;
for (int K = 1; K <= 2 * maxValue; K++) {
    int count = 0;
    for (int i = 0; i < n - 1; i++)
        for (int j = i + 1; j < n; j++)
            if (a[i] + a[j] == 2 * K) count++;
    ans = Math.max(ans, count);
}
```

(정수가 모두 다르다는 제한이 있으면 내 `|a-K|` 조건과 같은 결과다.) 더 빠르게 하려면 모든 쌍의 합을 `map(합 → 개수)`로 세고, 합이 짝수인 것 중 개수가 가장 큰 값을 고르면 된다. 쌍 전체를 한 번만 돌아서 O(N²).
